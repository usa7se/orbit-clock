# 星の時計

Notion や Web ページに埋め込める、宇宙テーマの軌道時計です。`index.html` 1ファイルだけで動きます。

## デザインの切り替え

URL の末尾で切り替えます。

| URL の末尾 | デザイン |
|---|---|
| （なし）または `?style=nebula` | 満月の星雲 |
| `?style=eclipse` | 日食 |
| `?style=corona` | 黄金のコロナ |
| `?style=lunar` | 満月と満ち欠け |

明るい背景のページに埋め込むときは `&theme=light` を付けます（例：`?style=corona&theme=light`）。時計の後ろに夜空の円が敷かれます。

## 時計の読み方

- 外側の軌道：時。月の形は実際の月齢と同じです
- 中央の軌道（目盛り付き）：分。毎時0分に新月、30分に満月になります
- 内側の軌道：秒。60秒で1周し、外周の小さな●が1秒で1周します
